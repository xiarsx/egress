# ADR-004：独立演进，不保持与 Resin 的线协议兼容

- 状态：已接受
- 日期：2026-10-19
- 相关：RFC-0001、ADR-002

## 背景

项目 fork 自 Resin 设计，最初承诺线协议兼容（身份协议 V1、错误码、
`X-Resin-*` 头、API 路径）。维护该承诺的前提是"存在需要兼容的外部
客户端生态"；实际并不存在，兼容只剩下成本：命名分叉、遗留环境变量
回退、默认目录沿袭、文档叙述双重身份。

## 决策

egress 独立演进，不保持与 Resin 的兼容。稳定契约由本项目自己的
`spec/` 定义并按 ADR-002 的 spec-first 流程演进；规范性命名的切换
一次性完成（见 RFC-0001）。派生署名保留在 LICENSE。

## 放弃的替代方案

| 方案 | 否决理由 |
|---|---|
| 继续承诺兼容 | 无受益方；每次契约演进都要背负对齐成本 |
| 双轨（兼容层可开关） | 永久冗余代码面，违背 P3/简洁性 |

## 后果

- 正面：命名全局一致（egress）；契约演进只需走内部 RFC；
  文档单一身份。
- 负面：理论上的 Resin 客户端需改名适配；上游 bugfix 不能自动继承。
